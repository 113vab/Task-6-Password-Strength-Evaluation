# Task 6 - Password Strength Evaluation

## Objective

Evaluate the strength of different passwords using an online password strength checker and understand how password complexity impacts security.

---

## Tools Used

* Password Meter
* Web Browser
* Screenshot Tool

---

## Passwords Tested

| Password                   | Strength    |
| -------------------------- | ----------- |
| password123                | Very Weak   |
| Vaibhav123                 | Weak        |
| Vaibhav@2026               | Fair        |
| V@iBh@v#2026!Cyber$ecurity | Very Strong |

---

## Key Observations

* Common passwords are cracked instantly.
* Personal names and predictable patterns weaken passwords.
* Adding special characters improves security.
* Longer passwords significantly increase resistance to attacks.
* Complex passwords require substantially more time to crack.

---

## Common Password Attacks

### Brute Force Attack

Attempts every possible password combination.

### Dictionary Attack

Uses a list of common passwords and words.

### Credential Stuffing

Uses leaked credentials from previous breaches.

### Phishing

Tricks users into revealing passwords.

---

## Security Best Practices

* Use passwords longer than 12 characters.
* Include uppercase and lowercase letters.
* Include numbers and special characters.
* Avoid personal information.
* Use unique passwords for every account.
* Enable Multi-Factor Authentication (MFA).
* Use a password manager.

---

## Conclusion

This task demonstrated how password length, complexity, and uniqueness affect password security. Strong passwords combined with MFA provide significantly better protection against unauthorized access and cyberattacks.
